# Sprint 10 chart behavior and defect register

## Compatibility inventory

The published package is `@iapps/d2-charts`. It exports `D2Charts`, the
deprecated `ChartVisualizer` alias, chart/core contracts, the Highcharts
adapter, the standard option transformation, and year-over-year services and
renderer. `D2Visualizer` imports the compatibility alias and delegates chart
types through its renderer registry.

`D2Charts` currently supports fluent `setId`, `setType`, `setConfig`, `setData`
and `setSelections` methods. Drawing mutates `config.config.type`, builds options
synchronously, and creates the Highcharts instance after a fixed 20 ms timer.
Repeated draws after a chart exists destroy the active chart before replacing
it. Two draws made before the first timer fires both create charts. Disposal is
idempotent.

PNG delegates to Highcharts offline export. CSV is generated by Highcharts and
downloaded with Blob/Object URL browser APIs. `XLS` is declared but is a no-op.

## Known defects

These are observations, not desired behavior. Pending tests express the desired
outcome; no passing assertion requires a defect to remain present.

| ID | Observation | Impact | Planned owner |
| --- | --- | --- | --- |
| CHART-001 | Missing and explicit-zero points both become numeric `0`; text `null` becomes an empty string. | Missing observations can be presented as measured zero. | Sprint 11 normalized dataset. |
| CHART-002 | Ordinary `AREA` receives `stacking: normal`. | Semantics differ from DHIS2 AREA versus STACKED_AREA. | Sprints 14-15 definitions/capabilities. |
| CHART-003 | Per-item axis assignment reads `axix`, not DHIS2 `axis`. | Valid secondary-axis configuration remains on axis zero. | Sprint 15 typed adapter. |
| CHART-004 | Multiple categories are built as `{name,categories}` objects internally, then sanitized to parent-name strings. | Inner category labels are lost and repeated parent labels can collapse. | Sprint 17 native categories. |
| CHART-005 | Structurally malformed analytics can be silently accepted as an empty chart; other malformed metadata can still cause incidental errors. | Consumers receive no stable, actionable validation result. | Sprint 11 boundary validation. |
| CHART-006 | `GAUGE` is handled internally but absent from public `ChartType`; `SOLIDGAUGE` is public. | Runtime and declaration capabilities disagree. | Sprint 14 capability registry. |
| CHART-007 | The gauge alias can leave chart-level type as `gauge` while series are `solidgauge`. | Highcharts interpretation depends on mixed options. | Sprint 14 gauge definition. |
| CHART-008 | `ChartType` contains `SINGLE_VALUE` and `YEAR_OVER_YEAR_LINE`, although the standard chart helper is not their correct path. | Direct `D2Charts` can accept semantically invalid combinations. | Sprint 14 validation/registry. |
| CHART-009 | `XLS` is a public `DownloadFormat` but chart download silently ignores it. | Consumer request appears successful with no artifact. | Future download contract decision. |
| CHART-010 | Rendering waits for an arbitrary fixed 20 ms timer. | Adds latency and complicates lifecycle ordering. | Later lifecycle work after equivalence proof. |
| CHART-011 | The accessibility module is not initialized. | Highcharts keyboard and screen-reader features are unavailable. | Sprint 19 release hardening. |
| CHART-012 | `highcharts-grouped-categories` remains a root dependency while initialization is implicit/outside the chart package. | Package behavior can depend on host side effects. | Sprint 17 removal. |
| CHART-013 | Current decimal-series aggregation averages values when any value has a fractional component but sums integer series. | Aggregation changes based on representation rather than declared semantics. | Sprint 12 transformation specification. |
| CHART-014 | The adapter has no explicit resize/reflow operation. | Resize behavior relies entirely on Highcharts/browser internals. | Future adapter contract decision. |
| CHART-015 | Two draws scheduled before either 20 ms timer fires both create charts. | Obsolete work renders briefly and consumes resources before replacement. | Later lifecycle/concurrency fix with explicit equivalence tests. |

## Residual baseline gaps

- Browser visual snapshots are not yet generated in a real browser; current
  characterization covers option structures and mocked lifecycle behavior.
- CSV browser download behavior remains covered indirectly by earlier tests and
  Highcharts adapter mocks; the blob contents are not parsed in Sprint 10.
- The facade tests mock chart drawing, so they prove dispatch/data ownership but
  not pixel equivalence with direct rendering.
- Gauge, radar and pie option branches are characterized without running the
  real Highcharts engine.
- The supplied DHIS2 documents target a known version snapshot; live-server
  round-trip payload testing remains outside this sprint.
