# D2 Components

D2 Components is a collection of Angular and TypeScript packages developed and maintained at UDSM DHIS2 Lab for building DHIS2 applications.

This documentation presents the shared entry point for package installation, usage examples, API notes, and maintainer guidance.

## Documentation structure

Each package has its own section under **Packages**. Start with the package index when you are not sure which package you need.
