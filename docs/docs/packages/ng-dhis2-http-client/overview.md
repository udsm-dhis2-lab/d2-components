# @iapps/ngx-dhis2-http-client

Angular HTTP client helpers for DHIS2 applications.

## Install

```bash
npm install @iapps/ngx-dhis2-http-client
```

## Build from source

```bash
npm run build:ng-dhis2-http-client
```
