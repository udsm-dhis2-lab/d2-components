# @iapps/ngx-dhis2-dictionary

Dictionary components and helpers for DHIS2 metadata workflows.

```bash
npm install @iapps/ngx-dhis2-dictionary
```

## Build from source

```bash
npm run build:ng-dhis2-dictionary
```
